# AI Resume Assistant

An AI-powered resume analyzer built with Streamlit and Google Gemini.

## 🚀 Live Demo

[Try the AI Resume Assistant](https://sananawaz488-ai-resume-assistant-app-jp4mdv.streamlit.app)

## ✨ Features

- Upload PDF or DOCX resume
- Estimated ATS score
- Resume strengths analysis
- Keyword alignment analysis
- Missing or weak sections
- ATS keyword suggestions
- Resume improvement recommendations
- Final action plan

## 🛠️ Technologies

- Python
- Streamlit
- Google Gemini
- PyPDF
- python-docx
